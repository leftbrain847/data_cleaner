How it works

generate (seeded) → inject faults → safe repairs → contract checks in DuckDB → clean / quarantine split → eval against what was injected. Every setting is in config/. Each contract also lists a SQL Server connection with env-var placeholders, so the same contract can be pointed at a work database later.
